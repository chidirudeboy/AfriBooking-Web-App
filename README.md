# AfriBooking Find & Book Web

Next.js web app for browsing apartments, booking stays, and reading public content.

## Development

Requirements:
- Node.js 18+
- npm

Install:
```bash
npm install
```

Run locally:
```bash
npm run dev
```

Useful commands:
```bash
npm run dev
npm run dev:clean
npm run dev:prod
npm run build
npm run build:prod
npm run start
npm run lint
npm run clear-cache
```
